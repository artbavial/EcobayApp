# Ecobay — патч v3.1 (ставится поверх v3)

Включает fix1 и fix2. Файлы из архива скопируйте в исходники с заменой, затем пересоберите и опубликуйте проект.

## Установка
1. Выполните `Sql/2026-10-25_PatchV3_1.sql`: он добавляет в Requests колонки PickupDate, PickupTime, RouteDriverId, RouteDate, RouteOrder и индекс. Скрипт можно запускать повторно.
   Есть и другой вариант: `dotnet ef database update`.
2. Пересоберите проект и нажмите Ctrl+F5, чтобы браузер не взял старые CSS и JS.

## Что нового
- **Главная.** Плашка цены стала полупрозрачной, в стиле плашки выбора города. Снизу первого экрана добавлен отступ, поэтому список городов больше не попадает под белую волну.
- **Вкладка «Маршруты».** Выберите водителя и день. Справа маршрут, слева свободные заявки, сгруппированные по городам. В каждой группе есть кнопки «В маршрут» и «Добавить все».
  - Порядок точек меняется кнопками ↑ и ↓, кнопка ✕ убирает заявку из маршрута.
  - Кнопка «Сгруппировать по городам» собирает точки одного города подряд. Порядок городов задаётся первой точкой: поставьте первой заявку из Жлобина — весь Жлобин окажется в начале, Гомель после него.
  - Кнопка «Печать» печатает только сам лист.
  - Если у заявки не было даты вывоза, при добавлении в маршрут ей ставится дата маршрута.
- **Дата и время вывоза.** Задаются при создании и при редактировании заявки (кнопка «Изменить»). Время указывать не обязательно. Есть быстрые кнопки «Сегодня / Завтра / Послезавтра».
- **Фильтр «Источник».** Варианты: «С сайта» или «Звонки (вручную)».
- **Водитель.** Главная вкладка — «Маршрут» на сегодня, точки идут в заданном порядке, день можно переключать стрелками или календарём. Вторая вкладка — «Все заявки».
