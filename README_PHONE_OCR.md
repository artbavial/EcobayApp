# Ecobay: распознавание белорусских телефонов на скриншотах

Небольшой патч поверх установленного единого обновления статистики. Содержит только `Components/App.razor`, `wwwroot/js/custom/custom.js` и эту инструкцию.

## Изменения

- Сохраняется поддержка `+375`, `375`, `80` и девятизначных мобильных номеров.
- Расширено распознавание внутренних форматов `8025`, `8029`, `8033`, `8044`: допускаются скобки, точки, пробелы, переносы и разделители между цифрами.
- Обрабатываются варианты `8 (029) 123-45-67`, `8-029-123-45-67`, `8 0 2 9 123 45 67`.
- Типографские тире и неразрывные пробелы не мешают извлечению.
- Латинская/кириллическая буква O/О исправляется на 0, распространённые OCR-варианты I/l/І/і/| на 1.
- Найденные номера приводятся к `+375XXXXXXXXX`, дубликаты исключаются.
- Проверяются границы сплошных цифровых последовательностей: номер не извлекается простым обрезанием более длинного числа.
- Для мобильных номеров без префикса сохраняется ограничение кодами 25/29/33/44. Поддержка ранее допустимых полных стационарных номеров не удаляется.

Обычный `8029...` поддерживался и раньше. Доработка расширяет именно варианты форматирования и ошибок текста OCR; серверная нормализация уже умеет приводить корректный `80...` к `+375...` и не меняется.

## Установка

Распаковать в корень исходников с заменой и опубликовать проект обычным способом. Миграция БД не нужна. Версия подключения JS изменена, чтобы браузер загрузил обновлённый файл.

Статистика, роли, меню и правила сохранения заявок этим патчем не меняются. В `App.razor` сохранены подключения аналитики из предыдущего патча.

## Проверки и ограничения

Проверены синтаксис JavaScript и извлечение из подготовленных текстовых примеров для всех четырёх мобильных кодов и нескольких вариантов оформления. Выполнена сборка .NET. Сам OCR на реальных скриншотах в рамках этой проверки не запускался.

Изображение всё равно должно позволять прочитать цифры: если OCR заменил одну цифру другой, восстановить правильный номер по формату нельзя. Как и раньше, перед сохранением нужно проверить предложенный номер. Если проблема повторится, нужен пример скриншота; тогда можно отдельно настроить обработку изображения.
