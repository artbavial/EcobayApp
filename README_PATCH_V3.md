# Ecobay — патч v3

Патч ставится поверх версии v2. В архиве лежат только новые и изменённые файлы. Пути в архиве такие же, как в проекте. Также в архиве есть `Ecobay-v3.patch` (git diff от v2) для `git apply`.

## Что сделано

- **Первый экран.** Иконки под телефоном убраны. Цена вынесена на отдельную плашку «МЫ ПЛАТИМ»: крупно «от 16» или «20–35», подпись «коп. за кг» и «Взвесим и оплатим сразу на месте». Режим «цена зависит от способа вывоза» (две карточки) остался без изменений.
- **Режим работы** везде одинаковый: «Заявки принимаем ежедневно, вывоз — с понедельника по субботу».
- **Отзывы и жалобы.** Под блоком отзывов есть кнопка «Оставить отзыв или жалобу», ссылка «Жалобы и предложения» в футере тоже открывает форму.
  - В форме: тип (отзыв, жалоба или предложение), город, имя, телефон и текст. Обязателен только текст.
  - Есть защита от ботов: скрытое поле и минимальное время заполнения.
  - Сообщения сохраняются в БД и дублируются на почту. В панели они в новой вкладке «Обращения», где их можно отметить обработанными и оставить комментарий.
  - На сайте отзывы не публикуются.
- **Автодобавка к целям.** В разделе «Цели» → «Автодобавка каждый час» есть включение и выключение, количество в час и часы работы (с/по).
  - Начисления выполняет фоновая служба внутри сайта.
  - Если сайт был выключен, пропущенные часы досчитываются при запуске (не больше чем за 30 дней).
  - Двойного начисления не бывает.
- **Раздел «Города»** переделан: слева список со статусами и заполненностью уникального текста, справа редактор с вкладками «Основное / Цены и телефон / Тексты и SEO / Промо» и одной кнопкой «Сохранить изменения». На телефоне сначала открывается список, затем город и кнопка «← Все города».
- **Ручная заявка.** «Заявки» → «Новая заявка»: скриншот, телефон, имя, город, адрес и описание.
  - Телефон со скриншота распознаётся прямо в браузере через Tesseract.js, без затрат на сервере. Если на скриншоте несколько номеров, можно выбрать нужный.
  - Скриншоты хранятся в `App_Data/uploads` и доступны только после входа в панель.
- **Роли «Администратор» и «Водитель».** Пользователи создаются во вкладке «Пользователи», там же меняется роль.
  - Водитель входит через `/admin/login` и попадает на `/driver`, где видны только заявки.
  - Водитель может отработать заявку (указать сумму, выплаченную клиенту, в рублях), отменить её или вернуть из отмены с комментарием.
  - Время обработки и исполнитель фиксируются, история изменений сохраняется.
  - Фильтры: не отработанные / отработанные / отменённые / все, город, даты, поиск.

## Установка

1. **Сделайте резервную копию БД.**
2. **Обновите БД** одним из способов:
   - выполнить `Sql/2026-10-25_PatchV3.sql` в SSMS (скрипт идемпотентный, повторный запуск безопасен);
   - или выполнить `dotnet ef database update`.

   Существующие пользователи панели останутся администраторами (`Role` по умолчанию `Admin`).
3. **Скопируйте файлы** из архива в исходники проекта с заменой.
4. **Опубликуйте проект:** `dotnet publish -c Release`, затем выложите результат публикации на хостинг. Если скопировать на сервер только `.razor` и `.cs`, изменения не применятся: нужна сборка.
5. **Дайте пулу приложения IIS право записи** в папку `App_Data` (там создаётся `uploads`).
6. **Чтобы автодобавка работала каждый час без пауз** (IIS), включите:
   - в пуле приложения Start Mode = AlwaysRunning, Idle Time-out = 0;
   - на сайте Preload Enabled = True.

   Если этого не сделать, пропущенные часы досчитаются при следующем открытии сайта.

## Замечания

- Все старые заявки после миграции получат статус «Новая». Если нужно, закройте старые одним запросом:
  `UPDATE Requests SET Status = 1, ProcessedAt = GETDATE(), ProcessedByName = N'Архив' WHERE Status = 0 AND DateCreate < '2026-10-20';`
- Распознавание телефона загружает Tesseract.js с cdn.jsdelivr.net при первом выборе скриншота (около 2–4 МБ, только в панели).
